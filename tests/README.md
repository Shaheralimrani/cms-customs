# Tests

هذا المجلد مخصص لاختبارات المشروع.

## الحالة الحالية
لم تُضف اختبارات آلية بعد. المشروع Plain PHP بدون framework،
والاختبار الحالي يدوي (يدوياً عبر المتصفح).

## خطة مستقبلية
- اختبارات وحدة (Unit) للـ Helpers والـ Validators
- اختبارات تكامل (Integration) للـ Services
- أدوات مقترحة: PHPUnit

## لماذا فارغ الآن؟
المشروع في مرحلة Portfolio. الاختبارات الآلية إضافة مستقبلية
عند التوسع. الاختبار اليدوي كافٍ للنطاق الحالي.
